REST API Documentation

This page documents the REST endpoints available in the Spring Boot Queue examples.

Base URL


http://localhost:8080

Apache ActiveMQ APIs

Method Endpoint Description
POST /activemq/send Send String Message
POST /activemq/send-json Send JSON Message

Send String Message



POST /activemq/send?message=Hello ActiveMQ

Response



Message sent successfully.

Send JSON Message



POST /activemq/send-json

Content-Type: application/json

{
  "id":1,
  "name":"Laptop",
  "price":55000
}

Response



JSON Message Sent Successfully.

HTTP Status Codes

Status Description
200 OK Request processed successfully.
400 Bad Request Invalid request payload.
404 Not Found Endpoint not available.
500 Internal Server Error Unexpected server error.

Postman Testing

  1. Start Docker containers.
  2. Run the Spring Boot application.
  3. Open Postman.
  4. Create a POST request.
  5. Call one of the endpoints.
  6. Verify the consumer logs.
