System Architecture

Understand how producers, queues, brokers and consumers communicate in the Spring Boot Queue examples.

Architecture Overview

The repository demonstrates asynchronous communication using Spring Boot with Apache ActiveMQ and RabbitMQ. Both implementations follow a producer-consumer pattern where messages are exchanged through a broker instead of direct service-to-service communication.

Message Flow

Step Description
1 Client invokes REST endpoint.
2 Controller validates request.
3 Producer publishes the message.
4 Broker stores the message.
5 Consumer receives the message.
6 Business logic processes the payload.
7 Application logs successful processing.

Producer Responsibilities

  • Accept REST requests.
  • Validate request payload.
  • Convert Java objects to messages.
  • Publish messages to broker.
  • Handle publishing failures.

Consumer Responsibilities

  • Listen for incoming messages.
  • Deserialize payload.
  • Process business logic.
  • Log message status.
  • Handle processing exceptions.

Broker Responsibilities

Responsibility Description
Queue Management Stores messages until consumed.
Routing Routes messages to consumers.
Persistence Stores durable messages.
Delivery Ensures reliable message delivery.
Monitoring Tracks queue statistics.

Benefits

  • Loose coupling between services.
  • Reliable asynchronous communication.
  • Scalable architecture.
  • Improved fault tolerance.
  • High throughput messaging.
  • Independent producer and consumer execution.
