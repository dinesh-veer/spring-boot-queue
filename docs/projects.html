Repository Projects

The repository contains multiple messaging examples built using Spring Boot and different queue technologies.

Available Projects

Each project demonstrates a different messaging platform with complete producer, consumer, REST APIs, configuration, and Docker support.

Spring Boot ActiveMQ

Demonstrates messaging using Apache ActiveMQ and JMS.

  • REST Producer API
  • REST Consumer API
  • String Messages
  • JSON Messages
  • Queue Configuration
  • Docker Support

Spring Boot RabbitMQ

Demonstrates messaging using RabbitMQ and AMQP.

  • Producer API
  • Consumer API
  • Exchange
  • Routing Key
  • Queue Binding
  • Docker Support
