Installation Guide

Follow these steps to configure and run the Spring Boot Queue examples on your local machine.

Prerequisites

  • Java 21 or later
  • Apache Maven 3.9+
  • Docker Desktop
  • Git
  • IntelliJ IDEA / Eclipse / VS Code

Clone Repository



git clone https://github.com/dinesh-veer/spring-boot-queue.git

cd spring-boot-queue

Verify Java



java --version

javac --version

Verify Maven



mvn --version

Start Docker

Ensure Docker Desktop is running before starting ActiveMQ or RabbitMQ.

Start ActiveMQ



cd spring-boot-activemq

docker compose up -d

Start RabbitMQ



cd spring-boot-rabbitmq

docker compose up -d

Build Project



mvn clean install

Run ActiveMQ Application



cd spring-boot-activemq

mvn spring-boot:run

Run RabbitMQ Application



cd spring-boot-rabbitmq

mvn spring-boot:run

Verify Application

Component Status
Spring Boot Running
ActiveMQ Broker Running
RabbitMQ Broker Running
REST APIs Available

Useful Maven Commands



mvn clean

mvn compile

mvn test

mvn package

mvn install

Useful Docker Commands



docker ps

docker images

docker compose up -d

docker compose down

docker logs

Import into IntelliJ IDEA

  1. Open IntelliJ IDEA.
  2. Select Open.
  3. Choose the repository folder.
  4. Import as a Maven project.
  5. Wait for dependencies to download.
  6. Run the Spring Boot application.

Troubleshooting

Issue Solution
Port already in use Stop existing application or change server port.
Docker container not starting Restart Docker Desktop.
Maven dependency failure Run mvn clean install -U.
Broker connection refused Verify broker container is running.
Application startup failure Check application.properties configuration.
