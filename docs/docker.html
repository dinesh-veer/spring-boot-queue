Docker Guide

Run Apache ActiveMQ and RabbitMQ locally using Docker for development and testing.

Overview

The repository includes Docker Compose configurations to quickly start the required messaging brokers without installing them manually.

Prerequisites

  • Docker Desktop
  • Docker Compose
  • Java 21+
  • Maven

Verify Docker



docker --version

docker compose version

docker ps

Start ActiveMQ



cd spring-boot-activemq

docker compose up -d

Stop ActiveMQ



docker compose down

Start RabbitMQ



cd spring-boot-rabbitmq

docker compose up -d

Stop RabbitMQ



docker compose down

Check Running Containers



docker ps

View Logs



docker logs <container-name>

Restart Container



docker restart <container-name>

Remove Containers



docker compose down -v

Useful Docker Commands

Command Description
docker ps List running containers.
docker images List downloaded images.
docker logs Display container logs.
docker exec -it Open container shell.
docker restart Restart container.
docker stop Stop container.
docker compose up -d Start services.
docker compose down Stop services.

Recommended Workflow

  1. Start Docker Desktop.
  2. Run Docker Compose.
  3. Verify broker container.
  4. Start Spring Boot application.
  5. Invoke REST APIs.
  6. Monitor broker dashboard.
  7. Check application logs.

Common Issues

Issue Solution
Docker daemon not running Start Docker Desktop.
Port already allocated Stop conflicting process.
Container exited Check container logs.
Broker unavailable Restart Docker Compose.
Image not found Run docker pull or docker compose up again.

Best Practices

  • Keep Docker Desktop updated.
  • Use Docker Compose for local development.
  • Monitor broker logs regularly.
  • Remove unused images periodically.
  • Persist broker data using Docker volumes.
  • Keep broker configuration externalized.
