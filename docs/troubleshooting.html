Troubleshooting Guide

Common problems encountered while running the Spring Boot Queue examples and their solutions.

Overview

This guide covers the most common issues related to Spring Boot, Maven, Docker, ActiveMQ, RabbitMQ, Java, networking and IDE configuration.

Common Issues

Issue Possible Cause Solution
Application won't start Configuration error Check application.properties and logs.
Port 8080 already in use Another application is running Stop the application or change server.port.
Maven build failed Missing dependencies Run mvn clean install -U.
Java not found JAVA_HOME not configured Configure JAVA_HOME correctly.
Docker daemon unavailable Docker Desktop stopped Start Docker Desktop.
Container exits immediately Invalid Docker configuration Check docker logs.
ActiveMQ not reachable Broker not running Start Docker Compose.
RabbitMQ connection refused Broker unavailable Verify container status.
Consumer not receiving messages Queue mismatch Verify queue name configuration.
Producer API returns 500 Broker connection failure Check broker URL and credentials.
JSON serialization failed Invalid payload Verify JSON structure.
ClassNotFoundException Dependency missing Reload Maven project.
Bean creation failed Spring configuration issue Review stack trace carefully.
Message lost Non-durable queue Enable durable queues.
IDE cannot resolve imports Maven not synchronized Reload Maven dependencies.
Docker image not found Image missing locally Run docker compose up again.
Application hangs during startup Broker unavailable Start broker before application.
Connection timeout Firewall or network issue Verify host and ports.
Consumer processes duplicate messages No acknowledgement strategy Configure acknowledgements properly.
Slow message processing Large payloads Optimize payload size.

Checklist

  • Java installed.
  • Maven installed.
  • Docker Desktop running.
  • Broker container started.
  • Correct application.properties.
  • Required ports are available.
  • Maven dependencies downloaded.
  • REST endpoints accessible.
  • Producer sending messages.
  • Consumer receiving messages.

Best Practices

  • Use the latest Java LTS version.
  • Keep Maven dependencies updated.
  • Always verify broker health before testing.
  • Use Docker Compose for local development.
  • Monitor application logs.
  • Use meaningful logging for producers and consumers.
  • Validate JSON payloads before sending.
  • Keep broker credentials externalized.

Still Having Problems?

If you are unable to resolve an issue:

  • Review the application logs.
  • Check Docker container logs.
  • Verify Maven dependencies.
  • Restart Docker and the application.
  • Create a GitHub issue with logs and steps to reproduce.
