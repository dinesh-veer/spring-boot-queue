Repository Features

Explore the features available across the Spring Boot Queue examples using Apache ActiveMQ and RabbitMQ.

Overview

The repository demonstrates enterprise messaging using Spring Boot with two popular message brokers: Apache ActiveMQ and RabbitMQ. Both projects follow similar application architecture while showcasing the unique capabilities of each broker.

Spring Boot

Built using the latest Spring Boot framework with annotation-based configuration.

REST APIs

Expose REST endpoints to publish messages without directly interacting with the broker.

Producer

Publish String and JSON messages to the configured broker.

Consumer

Automatically consume and process incoming messages.

JSON Messaging

Serialize and deserialize Java objects as JSON messages.

Docker Support

Run brokers locally using Docker and Docker Compose.
